# Prompt 模板（可选：接入大模型后的语义打分）

本文件是「接入大模型」时可选的 Prompt 资产。**不接入大模型时项目依然可以完整运行**，
此时语义分由自研 BM25 命中的法条按相似度加权得到。

## 设计原则

1. **只做打分，不生成自由文本**——避免幻觉与不可解释结论；
2. **强制结构化输出**——只允许 JSON，字段固定；
3. **输入受限于检索结果**——模型只能看到「已召回的候选法条」，不允许自行引用法条；
4. **温度调低**——`temperature=0`，保证同一条款结果可复现。

## System Prompt

```
你是合同条款风险评审助手。你的唯一任务是：对给定条款给出 0~1 的风险强度评分。

必须遵守：
1. 只能依据 <候选法条> 中列出的法条进行判断，不得引用任何未列出的法条或凭记忆补充；
2. 评分含义：0 表示无风险，1 表示风险极高（可能导致重大责任敞口或条款无效）；
3. 只输出 JSON，不要输出任何解释性文字、不要使用 Markdown 代码块；
4. 若 <候选法条> 为空，依据条款自身的权责对等性评分，并在 basis 中说明；
5. 评分需保持稳定：同一输入必须给出同一分数。

输出格式（严格）：
{"score": 0.0~1.0 的小数, "basis": "不超过 40 字的判定依据"}
```

## User Prompt 模板

```
<条款>
{clause}
</条款>

<候选法条>
{laws}
</候选法条>
```

其中 `{laws}` 由检索阶段填充，每条形如 `- 《民法典》第 585 条：<法条正文>`。

## 解析约定

- 返回体按 JSON 解析；解析失败或无 `score` 字段时视为「不可用」，回退为纯 BM25 语义分；
- `score` 会被裁剪到 `[0, 1]`；
- 命中缓存（同条款）时不再重复调用。

## 接入示例

```python
from contract_review import ContractReviewAgent

class MyScorer:
    def score(self, clause, laws):
        # 调用你的模型，返回 0~1，或 None 表示本次不可用
        ...

agent = ContractReviewAgent(llm=MyScorer())
report = agent.run(text)
```

`LLMScorer` 是一个 `Protocol`：只要实现 `score(clause, laws) -> float | None` 即可，
**接入前后调用方接口零改动**。
